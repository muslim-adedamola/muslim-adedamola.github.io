# muslim-adedamola.github.io

Source of my academic homepage, https://muslim-adedamola.github.io/ (served by GitHub Pages from `master`).

- `index.html`: the whole site (inline CSS, light and dark themes, no build step)
- `photo.jpg`: portrait
- `assets/Muslim_Alaran_CV.pdf`: public CV (no phone number)
- `assets/pubs/`: publication thumbnails cropped from the papers' figures
- `assets/projects/`: short muted clips and stills for the open-source projects

Preview locally with `python3 -m http.server` and open http://localhost:8000.
